# DilDal
DilDal — Atmospheric Cloud Enhancement for Kerbal Space Program
DilDal is a visual‑enhancement mod for Kerbal Space Program designed to transform the look and feel of Kerbin’s atmosphere by adding a fully custom cloud layer built for beauty, performance, and immersion. Instead of relying on heavy visual packs, DilDal focuses on delivering a lightweight, optimized cloud system that enhances the planet’s appearance without sacrificing framerate or gameplay stability. The mod introduces soft, dynamic, and aesthetically pleasing cloud formations that give Kerbin a more natural, vibrant, and alive atmosphere, making launches, re‑entries, and orbital views significantly more cinematic.

DilDal is built with simplicity in mind: no complicated settings, no massive texture packs, and no unnecessary dependencies. It aims to be the perfect “starter cloud mod” for players who want Kerbin to look better while keeping their game smooth, stable, and mod‑friendly. Whether you are flying low over the ocean, cruising through the upper atmosphere, or observing Kerbin from orbit, DilDal’s cloud layer adds depth, color, and realism to every moment.

This project is currently in early development (v0.1), meaning features, visuals, and performance will continue to evolve. Future updates may include improved texture resolution, additional cloud types, weather‑like patterns, and compatibility expansions for other celestial bodies. DilDal is created with the goal of becoming a clean, modular, and easy‑to‑maintain cloud system that can grow alongside the player community.

If you enjoy lightweight visual mods, atmospheric enhancements, or simply want Kerbin to feel more alive, DilDal is a simple yet powerful addition to your KSP experience.
